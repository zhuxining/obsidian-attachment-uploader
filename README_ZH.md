# 兼容性

需要 Obsidian 桌面版 **1.14.4 或更高版本**。上传依赖本地可执行程序，不支持移动端。

# obsidian-attachment-uploader

这个 Obsidian 插件可以帮助你上传本地附件到云存储，支持自定义上传命令和需要上传的附件格式。

## 功能

- 支持自定义上传命令
  - 内置[uPic](https://github.com/gee1k/uPic)上传命令`/Applications/uPic.app/Contents/MacOS/uPic -o url -u %s`
  - 内置[Picsee](https://picsee.chitaner.com/blog/Picsee_imageClound_command.html)上传命令`"/Applications/Picsee.app/Contents/MacOS/Picsee -u %s"`
- 自定义需要上传的附件格式
- 支持标准 Markdown 图片和 Wiki 嵌入，排除代码、注释和原始 HTML 区域
- 可选上传后删除原附件，默认关闭；遵循 Obsidian 回收站设置，有引用或检查不确定时保留
- 自动上传默认开启：粘贴截图、粘贴或拖入文件时上传，失败则回退为本地附件
- 本地回退也失败，或云端上传成功但链接未能插入时，通知会显示恢复位置或 URL
- 可选自动上传包含外链图片，默认关闭；仅处理粘贴的 Markdown 文本中的图片
- 支持手动转存当前文档中的 HTTP(S) 外链图片
- 支持批量迁移：扫描库内 Markdown 笔记，确认范围后上传引用的本地附件和外链图片；跳过打开的笔记，保留本地源文件
- 自动跳过本次会话已上传的结果，也可填写需要跳过的图片 URL 前缀

## 插件安装

1. 在 Obsidian 中，打开插件管理器
2. 搜索 "obsidian-attachment-uploader"
3. 点击 "安装",安装后启用并配置

## 使用配置

1. 安装带命令行接口的图床工具，或准备自定义上传程序
2. Obsidian attachment uploader 插件配置
   - **上传命令**：必须包含且仅包含一个独立的 `%s` 参数，用于传入附件本地路径。不支持直接使用 Shell 管道或变量展开；如有需要，可调用可信的可执行包装脚本。内置 uPic 和 Picsee 命令无需脚本。
   - **需要上传的附件格式**：配置需要上传的附件格式，以逗号或换行分隔
   - **上传后是否要删除原附件**：可选在附件链接成功替换后删除原附件
   - **自动上传**：默认开启，控制粘贴截图、粘贴或拖入文件时的上传。关闭后由 Obsidian 正常插入
   - **包含外链图片**：默认关闭；自动上传开启时，可同时转存粘贴的 Markdown 文本中的 HTTP(S) 图片。关闭主开关后此选项置灰并保留选择
   - **需要跳过的外链图片 URL 前缀**：可选，每行一个 HTTP(S) 前缀，按协议、主机、端口和路径目录匹配
3. 自定义命令示例
   - uPic 命令：`/Applications/uPic.app/Contents/MacOS/uPic -o url -u %s`
   - stdout 须输出唯一的 HTTP(S) 目标 URL，可带 `Output URL:` 标签，多个不同结果会被拒绝。
   - 输出示例：
     ```text
     Uploading ...
     Uploading 1/1
     Output URL:
     https://example.com/image.png
     ```

设置分为「上传工具」「上传选项」「跳过规则」。预设工具无需编辑命令；选择自定义时才显示命令输入。展开「测试上传」，输入本地文件路径，可执行一次真实上传；测试路径不保存。

修改库内已有附件不会自动上传。需要处理修改后的文件时，执行「上传当前笔记的附件」。允许格式也可加入 PDF、音频等扩展名；外链转存仅处理图片。

## 插件使用

1. 在 Obsidian 中打开包含附件的笔记
2. `command+p` 呼出面板，执行「上传当前笔记的附件」（英文：`Upload attachments in current note`），或点击左侧上传按钮
   此命令统一上传当前文档的本地附件并转存 HTTP(S) 外链图片。先处理已有外链图片，避免刚上传的本地附件再次被转存。
3. 需要粘贴时转存外链图片，可开启「自动上传」和「包含外链图片」。富文本粘贴保持 Obsidian 原有行为
4. 需要迁移整个知识库时，执行「批量迁移附件」。先「扫描知识库」确认待迁移笔记数和附件数，再「开始迁移」；可暂停、继续或取消

批量迁移只处理 Markdown 笔记引用的附件，不上传库内未被引用的文件。可填写排除文件夹；打开的笔记会跳过，关闭后重新扫描即可。附件按顺序处理，每项之间间隔 200 毫秒；连续三项失败或图片服务器返回限流时自动暂停。写入前会再次核对笔记内容和本地附件状态，无法确认时保留原链接；已上传但未能更新的地址会保存恢复记录，本地源文件始终保留。关闭迁移窗口不影响正在运行的任务，退出 Obsidian 会停止任务且不保存进度。

外链转存使用固定限制：单次最多 100 个不同 URL，同时下载 3 张，单图 20 MiB，单批累计 200 MiB，单张下载 30 秒，最多重定向 3 次。

手动上传只处理当前文档，不受自动上传开关影响。本地附件和外链图片使用一个进度提示、取消按钮和汇总结果。取消后停止后续处理；已经运行的上传命令可能完成，成功但未应用的 URL 会保存恢复回执。重复点击同一文档的上传操作不会重复启动任务。

切换插件的上传服务或命令会重置会话上传记录，手动填写的前缀保留。重启后，如需跳过图床已有图片，请配置 URL 前缀；未配置时，手动转存可能再次上传这些图片。取消可阻止等待中的上传，已运行的上传仍可完成。
